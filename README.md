# Namy Goto | Landing Page

Landing page de alta conversão para **Namy Goto** (Influencer de Lifestyle, Beleza e Cultura Japonesa).

## 🎨 Estética & Design
- **Estilo:** Retrô, Girly, Y2K, "Old Internet"
- **Paleta de Cores:**
  - Primária: `#D1202D` (Vermelho)
  - Secundária: `#F49CBB` (Rosa)
  - Fundo: `#F0EEE6` (Bege)
  - Destaque: `#CBEEF3` (Azul Claro)
  - Texto: `#24110C` (Marrom Profundo)

## 🛠️ Tecnologias
- HTML5 Semântico
- CSS3 (Flexbox & Grid com Variáveis CSS)
- Vanilla JavaScript

## 🚀 Funcionalidades
- **Hero Section:** Animação estilo polaroid e letreiro marquee infinito.
- **Bio (Sobre Mim):** Apresentação com layout responsivo e elementos visuais com gradientes.
- **Portfólio Interativo:** Switcher de vídeos em tempo real para categorias (*Beauty*, *Comidinhas*, *Lifestyle* e *Nipo*).
- **CTA & Contato:** Interface no estilo teclado mobile com atalho direto para e-mail e redes sociais.
